# AirNow Bundle

`survos/airnow-bundle` provides a small typed AirNow API client with Survos Fetch caching
and transport and Survos Kit bundle conventions. PHP 8.5 / Symfony 8.1.

Current capability: current forecasts and current NowCast observations by ZIP using replacement endpoints.
See README.md for usage and PLAN.md for the endpoint migration and desktop milestones.
